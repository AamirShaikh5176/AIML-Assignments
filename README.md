## 🔬 Topics Covered

### 1. Association Rule Mining / Regression

This assignment introduces the concepts involved in discovering relationships within data and applying regression techniques where required.

### 2. K-Means Clustering

Implementation of the **K-Means clustering algorithm** for grouping similar data points into clusters. The assignment also demonstrates how clustering results can be visualized.

### 3. Principal Component Analysis

Implementation of **PCA**, a dimensionality reduction technique used to transform high-dimensional data into a smaller number of principal components while retaining important information.

### 4. Naive Bayes

Implementation of the **Naive Bayes classification algorithm**. The assignment demonstrates how probability-based classification can be used to classify data into different categories.

### 5. K-Nearest Neighbors

Implementation of the **KNN classification algorithm**, where the class of a data point is determined based on the classes of its nearest neighboring points.

### 6. Linear Regression

Implementation of **Linear Regression** to model the relationship between dependent and independent variables and make predictions using the trained model.

### 7. Support Vector Regression

Implementation of **Support Vector Regression (SVR)** for predicting continuous numerical values using the Support Vector Machine approach.

## ▶️ How to Run

### Using Google Colab

1. Open the required `.ipynb` file from this repository.
2. Click **Open in Colab** or download the notebook and upload it to Google Colab.
3. Run the cells sequentially.
4. Make sure the required Python libraries are available.
5. View the generated outputs, graphs, and model results.

### Using Jupyter Notebook

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

Navigate to the project directory:

```bash
cd your-repository-name
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the required assignment notebook and execute the cells.
